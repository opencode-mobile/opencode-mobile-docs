Install via TestFlight

Get OpenCode Mobile — Unofficial through Apple’s TestFlight Internal Testing. This is a private team channel — not the App Store.

You must be an App Store Connect team member for this app. Internal Testing does not use public invite links or External Testing groups. After install, connect the app to your server with the connection guide.

0

Before you start

What you need on the device

  • An iPhone or iPad signed into the Apple ID that was added to the App Store Connect team
  • The free TestFlight app from the App Store
  • A build that has finished Apple processing (someone on the team usually triggers upload)
1

Install the build

On your physical device

Steps

  1. Install TestFlight from the App Store if you don’t already have it.
  2. Open TestFlight while signed in with your invited Apple ID.
  3. Find OpenCode Mobile — Unofficial.
  4. Accept the invite if prompted, then tap Install (or Update).
  5. Launch the app from TestFlight or the Home Screen.

Still processing? New uploads can sit in “Processing” in App Store Connect for a while. The build only appears in TestFlight after Apple finishes that step.

2

After install

Point the app at your opencode server

  1. Open the app and complete or skip onboarding if shown.
  2. Follow Connect to an opencode server (Tailscale recommended).
✓

Checklist

Quick confirmation

  • Apple ID is on the App Store Connect team
  • TestFlight app installed
  • Build visible and not stuck in Processing
  • App installs and opens
  • Server connection saved
