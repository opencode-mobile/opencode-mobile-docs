Install via TestFlight

Get OpenCode Mobile — Unofficial through Apple’s TestFlight. Anyone with the join link can install — this is not the App Store.

Self-invite: open the TestFlight join link on your iPhone or iPad, accept, then install. After install, follow the connection guide.

0

Before you start

What you need on the device

  • An iPhone or iPad (open the join link on the device, not only on a computer)
  • The free TestFlight app from the App Store
1

Join and install

On your physical device

Steps

  1. Install TestFlight from the App Store if you don’t already have it.
  2. Open the join link on the same iPhone or iPad.
  3. Accept the TestFlight invite if prompted.
  4. On OpenCode Mobile — Unofficial, tap Install (or Update).
  5. Launch the app from TestFlight or the Home Screen.

Join on TestFlight

testflight.apple.com/join/psaUBVsa

Open it on the phone. A desktop browser may show the TestFlight page, but you accept and install in the TestFlight app on iOS.

2

After install

Point the app at your opencode server

  1. Open the app and complete or skip onboarding if shown.
  2. Follow Connect to an opencode server (Tailscale recommended).
✓

Checklist

Quick confirmation

  • TestFlight app installed
  • Opened the join link on the iPhone or iPad
  • Invite accepted and app installed
  • App opens from TestFlight or the Home Screen
  • Server connection saved
Troubleshooting
SymptomLikely cause
Link doesn’t offer Install TestFlight isn’t installed; opened the link on a computer instead of the device
App never appears in TestFlight Invite not accepted yet; wrong Apple ID signed in on the device
Beta isn’t accepting new testers Tester cap reached — try later or ask the maintainer
Only an old build shows Newer TestFlight build not released yet; wait or check with the maintainer
