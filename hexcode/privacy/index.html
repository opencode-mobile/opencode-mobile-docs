Hex Code Privacy Policy

How Hex Code for OpenCode handles data. Last updated: 17 November 2026.

Hex Code is an unofficial third-party app for opencode. It is not made by, affiliated with, or endorsed by the opencode project. This page covers the Hex Code iOS and Android apps only. It does not cover your opencode server or the opencode project. OpenCode Mobile has its own policy.

Who we are

Hex Code for OpenCode is an independent app from the publisher of OpenCode Mobile — Unofficial. It has no account system. It talks to the opencode server you pair it with and, once, to Hugging Face for its speech model. We run no server for it, and nothing it handles is sent to us.

Your voice

When you hold the talk button, Hex Code records from the microphone and turns your speech into text on the phone, with a speech model stored on the phone. Audio is never sent to your server, to us, or to anyone else.

A recording is kept in the app's private storage only until it has become text. If the model is still downloading, or turning a recording into text fails, the recording waits there so you can try again. It is deleted when it has become text or when you clear the draft. A recording left behind when the app closes is deleted the next time the app starts, on both Android and iPhone.

The text stays on the phone as a draft until you send it.

Speech model download

The speech model (about 600 to 700 MB) is downloaded once from Hugging Face (huggingface.co and the servers it uses to deliver files). The request asks for fixed, public model files. Like any download, it carries your IP address and a standard software identifier from the phone's networking library. It contains no speech, no messages, and no identifier from Hex Code. Hugging Face's own privacy policy covers that request.

The model stays on the phone until you uninstall the app. On iPhone it is left out of iCloud and device backups.

Your server

Hex Code works with the opencode server you pair it with, normally on your own computer. It sends that server:

  • The pairing code from the QR you scan, once, to get the password the app uses from then on.
  • The messages you send, your answers to the agent's permission requests and questions, goals, side questions, and Stop.
  • Photos you attach or take. They are resized and saved again as JPEG first, which leaves out location and other photo metadata.
  • Files and videos you attach, unchanged, including any metadata they contain. They are written to a temporary folder on the server for the agent to open.
  • Requests for short summaries of the agent's work, which your server writes with the model you set up in opencode.

The app reads your sessions, the agent's status, to-do lists, summaries, and artifacts from the server to show them to you.

What your server does with this content is outside this policy. That includes passing it to the AI model provider you chose in opencode, and any logging on the server. If you pair with opencode pair --remote, traffic goes through the tunnel that command sets up, not through anything run by us.

Hex Code uses encrypted https for addresses on the internet. It allows plain http only to addresses on your own network, Tailscale, or the phone itself, where an opencode server is usually reached that way. Plain http on your network is not encrypted. Use Tailscale, a VPN, or https if that matters to you.

In-app browser

The app's browser opens your dev server's localhost pages at your computer's address, and the agent's artifacts through your opencode server. Links to other sites open in your phone's browser. Cookies and site storage from those pages stay on the phone so a page's sign-in lasts between opens. Forget this computer clears them.

On this device

The server password stays in iOS Keychain or Android Keystore-backed storage. The server's addresses, username and name, your project folder, model choice, appearance, today's session, the last status card, and your recent side questions stay in ordinary app storage. Photos and files you attach are copied into the app's cache while they are prepared and sent.

Android backups are turned off for Hex Code. On iPhone, ordinary app storage is included in your own iCloud or computer backups. The password is not, and the speech model is not.

The app writes short technical messages to the phone's system log, such as timings and errors, for troubleshooting. They are not meant to hold your messages, though a web address you opened can appear. They stay on the phone. Hex Code never sends them.

What Hex Code does not do

  • No accounts and no sign-in with us.
  • No analytics, crash reporting, or usage tracking.
  • No ads, no advertising ID, and no tracking across apps or websites.
  • No sale or sharing of data. We never receive it.
  • No location, contacts, or calendar access.

Permissions

Permission Why
Microphone Dictation, turned into text on the phone.
Camera Scanning the pairing QR code your computer shows, and taking photos you send with a message.
Local network (iOS), internet and network state (Android) Reaching your opencode server and downloading the speech model.

Photos, videos and files are chosen with the system picker, so Hex Code does not ask for access to your whole photo library or storage.

Deletion

We hold no data about you, so there is nothing for us to delete. Data on the phone is yours to remove:

  • Settings → Forget this computer removes the server, its password, the project and model, the saved status card, side-question history, and in-app browser data.
  • Clearing the draft deletes any recordings waiting to become text.
  • Uninstalling the app removes everything it stored, including the speech model. On Android, App info → Storage → Clear storage does the same without uninstalling.

Sessions, messages and uploaded files live on your opencode server. Delete them there.

Children

Hex Code is for people 18 and over and is not directed at children.
