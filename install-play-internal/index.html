Install via Google Play

Get OpenCode Mobile — Unofficial from Google Play. The listing is public. Install it on the device the same way you install any other Play app.

Open the Play Store listing on your Android device and tap Install. After install, follow the connection guide.

0

Before you start

What you need on the device

  • A physical Android device (or emulator) signed into Google Play
  • The Google Play Store app

Coming from an older sideloaded / Firebase APK? Uninstall that copy first. Different signing certificates won’t update in place.

1

Install from Play Store

On your physical device

Steps

  1. Open the Play Store listing on the Android device.
  2. On OpenCode Mobile — Unofficial, tap Install (or Update).
  3. Launch the app from Play or the app drawer.

Open on Google Play

play.google.com/store/apps/details?id=dev.opencode.mobile
2

After install

Point the app at your opencode server

  1. Open the app and complete or skip onboarding if shown.
  2. Follow Connect to an opencode server (Tailscale recommended).
✓

Checklist

Quick confirmation

  • Opened the Play Store listing on the device
  • Old sideloaded copy uninstalled if switching
  • App installs and opens from Play
  • Server connection saved
Troubleshooting
SymptomLikely cause
App listing missing or Install unavailable Play Store isn’t signed in, or this device has no Play Store. Open the listing link on the phone.
Install fails / “App not installed” Existing sideloaded build still installed — uninstall it, then install from Play
Only an old build shows Play is still rolling out the newer release. Refresh the store listing, or check again later.
