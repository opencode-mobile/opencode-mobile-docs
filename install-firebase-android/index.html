Install via Firebase App Distribution

Install the signed APK of OpenCode Mobile — Unofficial from a private Firebase tester group. New merges to main ship here automatically.

Access is invite-only (group android-internal). There is no public invite link — request access first. This channel uses a different signing certificate than Play internal testing — see the migration note below. After install, use the connection guide.

0

Before you start

What you need

  • Your email was added to the private Firebase group android-internal
  • A physical Android device (or emulator that can install APKs)
  • Willingness to allow installs from Firebase / browser when Android prompts

Coming from Play internal testing? Uninstall the Play-delivered app first. The certificates differ, so Android won’t update in place. Later Firebase builds can update each other normally.

Install from Firebase

Tester experience on the device

Steps

  1. Open the Firebase App Distribution email invite (or a release link the maintainer sent).
  2. Sign in with the invited Google account if prompted.
  3. Accept the tester invite the first time.
  4. Open the latest OpenCode Mobile — Unofficial release.
  5. Tap Download, then install the APK.
  6. If Android blocks the install, allow the browser or Firebase App Tester to install unknown apps, then retry.
  7. Launch the app.

Where releases come from

Every push to protected main can produce a new upload-key-signed APK for android-internal. Version codes use a high reserved range so they don’t collide with Play internal builds.

Connect to your server

  2. Follow Connect to an opencode server.

Troubleshooting
SymptomLikely cause
Install blocked / “App not installed” Existing Play-signed app still installed; unknown-sources not allowed; wrong architecture rare
No invite / no releases Email not in android-internal; wrong Google account signed in
Want Play Store delivery instead Ask the maintainer for Play internal testing access (separate channel from Firebase)
Switching back to Play internal Uninstall the Firebase build, then install from Play again
