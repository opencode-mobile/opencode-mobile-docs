Install via the App Store

Get OpenCode Mobile — Unofficial from the App Store. The listing is public. Install it on the iPhone or iPad the same way you install any other App Store app.

Open the App Store listing on your iPhone or iPad and tap Get. After install, follow the connection guide.

0

Before you start

What you need on the device

  • An iPhone or iPad on iOS 17.5 or iPadOS 17.5 or later
  • The App Store, signed in

Still on the TestFlight build? Delete that copy, then install from the App Store. Store updates go to the App Store app.

1

Install from the App Store

On your iPhone or iPad

Steps

  1. Open the App Store listing on the iPhone or iPad.
  2. On OpenCode Mobile — Unofficial, tap Get (or the cloud icon to reinstall).
  3. Launch the app from the Home Screen.

Open on the App Store

apps.apple.com/app/opencode-mobile-unofficial/id6799246544

Open it on the phone. A desktop browser can show the listing, but you install in the App Store on the device.

2

After install

Point the app at your opencode server

  1. Open the app and complete or skip onboarding if shown.
  2. Follow Connect to an opencode server (Tailscale recommended).
✓

Checklist

Quick confirmation

  • Opened the App Store listing on the iPhone or iPad
  • Old TestFlight copy removed if it was still installed
  • App installs and opens from the Home Screen
  • Server connection saved
Troubleshooting
SymptomLikely cause
Listing missing or Get unavailable App Store isn’t signed in, the device is below iOS 17.5, or the link was opened on a computer. Open it on the iPhone or iPad.
TestFlight build is still the one that opens The beta copy is still installed. Delete it, then install from the App Store.
Only an old build shows The App Store is still rolling out the newer release. Refresh the listing, or check again later.
