Shipped

8
Terminal and chat history crashes Opening Terminal on Android 11, or a chat whose messages overlap out of order, no longer crashes the app.
Chip timeline Settings can switch Session Chat to chips under each paragraph. Explore bursts collapse into one Explored chip, and a one-time sheet can turn the view on.
MCP servers on Commands Commands shows a read-only list of MCP servers on the connected server, with status for each one.
Finished turns when you come back Returning to an open chat shows the completed turn, and a normal send no longer flashes Syncing.
Up next strip While a session is working, waiting prompts sit in one strip above the composer that opens an Up next sheet.
Drag to reorder projects Long-press and drag projects in the filter picker. The order sticks for that connection.
Long chats open faster Opening a long chat skips the huge tool-output download the first screen never shows.
Terminal Home opens a live shell for the selected project, including on a v2 server.

3

Session export Export the open session through the share sheet. The file format is still to be chosen.
