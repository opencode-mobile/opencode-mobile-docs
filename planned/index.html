Roadmap

Planned work

Features and fixes lined up after the current tester builds. Ordered by priority so you can see what is next versus later.

This is a living snapshot, not a ship date. Order and scope can change as testing feedback comes in. Release plumbing and private operator work stay off this list.

1

Next up

Higher priority — earliest you should expect

OpenCode v2 server support

Connect to both classic OpenCode servers and newer v2 servers without changing how you use the app. Protocol is detected on connect so newer OpenCode installs stop failing as a pure v1 client.

Collapse consecutive tool calls

Optionally fold back-to-back tool calls in Session Chat into one summary card. Toggle under Settings → Appearance; off by default.

Composer agent picker

Choose any primary agent from the connected server — including your custom agents — instead of only Build and Plan. Matches how desktop and TUI already cycle agents from server config.

Fork session from chat

Fork the open session from the overflow menu, or fork from a specific outgoing message. Name the fork, then open it or stay on the original.

2

Planned

On the list after the next-up items

Jump-to-bottom button flicker (Android)

In Android chat, the floating button that jumps to the latest messages can flash on and off when you stop scrolling near the bottom. Make it stay steady instead.

File browser

Browse directories and open file contents for the active project on the connected server. Viewer-first; editing is out of scope for this slice.

@ file mentions

Type @ in the composer to fuzzy-match project files and insert structured file references into a prompt, alongside agent mentions.

Session export

Export an open session for sharing or archival (Markdown, JSON, or the system share sheet — format still to be locked).

3

Later

Useful, but lower priority or still scoping

Remote terminal

Some form of remote shell against the server host — interactive PTY, one-shot shell commands in chat, or shell-output rendering. Product shape is still open; not all three will ship together.

MCP server list

Read-only list of MCP servers configured on the connected opencode server, with status. Connect / OAuth / tool invocation UI comes later.

Not a ship calendar. No public store dates, no promise that every item lands in this order, and no CI / signing / operator-only release work on this page.
