Roadmap

Planned work

What is next, what is still on the list, and what already landed in tester builds.

This is a living snapshot, not a ship date. Order and scope can change as testing feedback comes in. Release plumbing and private operator work stay off this list.

Next up Planned Shipped Later

Next up

4
Collapse consecutive tool calls Optionally fold back-to-back tool calls in Session Chat into one summary card. Off by default.
Running child session as a chat row A running subagent looks like a quiet thread row in the parent chat, not a generic tool card.
Composer agent picker Choose any primary agent from the connected server, including custom agents — not only Build and Plan.
Fork session from chat Fork the open session, or fork from a specific outgoing message, then open it or stay.

Planned

6
Jump-to-bottom button flicker (Android) The floating jump button can flash on and off when you stop scrolling near the bottom.
Project picker on home Replace the home project chip scroller with a single picker so filtering still works when many projects are added.
Simpler home with one project With a single added project, skip the All chip and the extra project picker when starting a new session.
File browser Browse directories and open file contents for the active project. Viewer-first; no editing in this slice.
@ file mentions Type @ in the composer to fuzzy-match project files and insert them into a prompt.
Session export Export an open session for sharing or archival. Format still to be locked.

Shipped

6
OpenCode v2 server support Connect to classic and newer v2 servers. Protocol is detected on connect.
Session Chat freeze (iOS) Sending and opening a session no longer lock up TestFlight builds.
Keyboard hides when you send The composer dismisses on send so the timeline can use the screen.
Project name in the chat top bar See which project a session belongs to without leaving chat.
Long-press sessions on home Rename, fork, archive, or delete from the Session List without opening chat.
Remove a project from home Drop a project from the Session List dock without deleting its sessions on the server.

Later

3
Multiple connection profiles Save more than one server, switch which one home shows, and add or remove profiles without mixing sessions.
Remote terminal Some form of remote shell. Product shape is still open.
MCP server list Read-only list of MCP servers on the connected opencode server.
