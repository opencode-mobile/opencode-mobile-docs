Install via Firebase App Distribution

Install the Ad Hoc build of OpenCode Mobile — Unofficial from a private Firebase tester group. New merges to main ship here automatically.

Access is invite-only (group ios-internal). There is no public invite link — request access first. Your device UDID must be registered for Ad Hoc signing before the build will install. After install, use the connection guide.

0

Before you start

Operator + device prerequisites

  • Your email was added to the private Firebase group ios-internal
  • Your device UDID was registered with Apple and included in a new Ad Hoc build
  • You can open email on that same iPhone / iPad (or the Firebase App Tester app)

New device? Tell the maintainer your UDID. After they register it, wait for a new App Distribution build — old builds won’t include your device.

Install from Firebase

Tester experience on the device

Steps

  1. Open the Firebase App Distribution email invite (or a release link the maintainer sent).
  2. Sign in with the invited Google account if prompted.
  3. Accept the tester invite the first time.
  4. Open the latest OpenCode Mobile — Unofficial release.
  5. Tap Download / Install and follow the on-device prompts.
  6. If iOS asks you to trust the developer, go to Settings → General → VPN & Device Management and trust the profile, then open the app.

Where releases come from

Every push to protected main can produce a new Ad Hoc IPA for ios-internal. Build numbers are in a high range (separate from TestFlight) so the two channels don’t collide.

Troubleshooting
SymptomLikely cause
Install fails / “Unable to Install” UDID missing from the Ad Hoc profile; need a newer build after registration
No invite / no releases Email not in ios-internal; wrong Google account signed in
Conflict with TestFlight build Uninstall the TestFlight copy, then install the Firebase Ad Hoc build
Want ASC team installs instead Use TestFlight Internal Testing
